# content

Учебный контент v0.2 отделён от интерфейсной логики:

- `sources.js` — реестр источников, приоритет согласованных редакционных решений, общая иерархия и известные расхождения;
- `modules.js` — маршрут, учебные разделы модулей 01–02 и структурированные незавершённые модули 03–06;
- `questions.js` — банки вопросов по идентификатору модуля;
- `practice.js` — уровни практики, услуги и критерии наставника.

Файлы создают структуры `window.TOPGUN_*` и подключаются до `app.js`. Такой формат выбран вместо JSON с `fetch()`, чтобы приложение открывалось двойным кликом через `file://`.

Новый конфликт источников нельзя разрешать в контенте автоматически: сначала добавить его в `sources.js` и получить редакционное решение.
