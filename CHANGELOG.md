# CHANGELOG

## v0.2 — 2026-08-14

### Реализовано

- Реальный маршрут стажировки из шести занятий по «Методичке для мастер».
- Полные модули 01 и 02 с отмечаемыми учебными разделами, тестами 6/8 и 8/10 и подтверждением наставника.
- Пять практических услуг с последовательностью «наблюдал → выполнил с наставником → выполнил самостоятельно».
- Раздельный учёт завершения занятия, уровня навыка и решения наставника.
- Автоматическое открытие следующего занятия и отдельное ручное открытие наставником без ложного зачёта.
- Реестр источников, согласованных редакционных решений и известных расхождений.

### Архитектура

- Добавлены `content/sources.js` и `content/practice.js`; сохранён локальный `file://`-совместимый формат.
- Прогресс переведён на `progressSchemaVersion: 2` с резервной записью исходного v1 JSON и переносом только имени.
- UI-логика обобщена для нескольких полных модулей и разных размеров тестов.
- Учебный контент, вопросы, практика и реестр источников отделены от UI-кода и подключаются локальными JavaScript-файлами без `fetch()`.

### Реальные источники

- `Методичка для мастер.docx` — структура стажировки и содержание занятий.
- `Регламент_TOPGUN_По_оказанию_услуг_2021_03_08.pdf` — точные тайминги и подтверждённые технологические последовательности.
- `Методичка по обслуживанию и консультации - переверстанная.pdf` — клиентский путь и сервис.
- `Должностная_инструкция_Барбера_TOPGUN_Казань.docx` — роль, культура и требования к барберу.
- `TOPGUN by RESEDA ODOR.pdf` — ознакомительная информация о конкретной косметике без конструирования технологии услуги.

### Редакционные границы

- Для дезинфекции модуля 01 закреплено согласованное исключение из основной методички.
- RESEDA используется только как ознакомительный продуктовый контекст.
- Отсутствующие технологии ухода за кожей головы и детокса не выдумываются.
- Модули 03–06 остаются структурированными незавершёнными модулями.

### Ограничения

- Полное учебное наполнение модулей 03–06 остаётся за пределами v0.2.
- Не добавлены отсутствующие в источниках технологии детокса и премиум-ухода за кожей головы, а также не выдумана корпоративная форма карты клиента.
- Нет аккаунтов, сервера, синхронизации и автоматического профессионального допуска.

### Стабильная контрольная версия

- Пользовательская проверка v0.2 пройдена.

## v0.1 — 2026-08-10

### Реализовано

- Локальное браузерное приложение «TOPGUN · Старт» для демонстрационного маршрута стажёра.
- Маршрут из 6 модулей с ясными состояниями: завершён, сейчас, закрыт и демо-структура.
- Полный демонстрационный модуль «02 · Клиент и сервис»: материал, чек-лист 5/5, тест из 8 вопросов, практика и ручное решение наставника.
- Повторные попытки теста, проходной результат 6/8, сохранение попыток и тем для повторения.
- Решения наставника «Ожидает проверки», «Нужно повторить», «Принято» и сохранение комментария.
- Завершение модуля только при чек-листе 5/5, успешном тесте и принятой практике.
- Подтверждённый сброс демо-прогресса.

### Архитектура

- HTML, CSS и vanilla JavaScript без зависимостей, сервера и внешних API.
- `index.html` открывается двойным щелчком через `file://` и последовательно подключает локальные данные `content/modules.js`, `content/questions.js`, затем `app.js`.
- Учебный контент отделён от логики интерфейса и выводится безопасными DOM-узлами без исполнения HTML из контентных файлов.
- Прогресс хранится локально в `localStorage` под версионированной схемой `progressSchemaVersion: 1`.

### Проверено

- Прямой запуск `index.html` без HTTP-сервера и без ошибок JavaScript в консоли.
- Полный путь: чек-лист → неуспешный тест → успешный тест → возврат практики → принятие практики → завершение модуля.
- Сохранение имени, ответов, попыток, статуса практики и комментария после повторного открытия страницы.
- Подтверждённый сброс локального прогресса.
- Адаптивное отображение на ширине 390 px без горизонтального переполнения.

### Известные ограничения

- Полностью реализован только демонстрационный модуль 02; остальные этапы являются структурными заглушками.
- Учебный контент демонстрационный и не является официальным стандартом TOPGUN.
- Нет аккаунтов, синхронизации между устройствами, сервера, базы данных, удалённого кабинета наставника, интеграций и аналитики.
- Практический допуск остаётся ручным решением наставника; приложение не оценивает профессиональную пригодность.
