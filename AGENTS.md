# AGENTS.md
## TOPGUN · Старт

Перед работой обязательно прочитай `PRODUCT_SPEC.md`.

### Scope
Это локальный MVP стажировки, не полноценная LMS.
Не расширяй scope без прямого запроса.

### Контент
- Не выдавай демонстрационные тексты за официальные стандарты TOPGUN.
- Не придумывай реальные внутренние правила компании.
- Держи учебный контент отдельно от UI-кода.
- Новый модуль должен добавляться через контентную структуру с минимальными изменениями приложения.

### Прогресс
- Сохраняй прогресс локально.
- Не теряй его после перезапуска браузера.
- Сброс требует подтверждения.

### Проверка
- Тесты можно проверять автоматически.
- Практический допуск подтверждает наставник.
- Не автоматизируй решение о профессиональной пригодности сотрудника.

### Интерфейс
- Русский язык.
- Reference HTML задаёт механику, но визуал нужно улучшить.
- Стиль: premium TOPGUN, dark graphite, amber accent.
- Не использовать неоновый киберпанк и generic SaaS-визуал.
- Не перегружать экран.
- Чётко различать статусы: завершено / сейчас / закрыто.
- Объяснять ошибки простым языком.

### Архитектура
Предпочитать:
- HTML/CSS/vanilla JS;
- JSON-контент;
- localStorage.

Не добавлять без необходимости:
- React;
- сервер;
- базу данных;
- Docker;
- API;
- облако.

Если `file://` мешает чтению JSON, сначала предложи минимально сложное решение и объясни компромисс.

### Работа с изменениями
Перед крупным изменением:
1. покажи короткий план;
2. перечисли файлы;
3. назови риск.

После изменения:
1. проверь базовый сценарий;
2. проверь сохранение прогресса;
3. проверь повторный запуск;
4. сообщи оставшиеся ограничения.

### Источник истины
Функциональные требования находятся в `PRODUCT_SPEC.md`.
