# TOPGUN · Старт v0.2

Локальное приложение для сопровождения реального маршрута стажировки нового барбера. Работает на одном устройстве без аккаунтов, сервера и интернета.

## Запуск

Дважды щёлкните по `index.html`. Установка и терминал не нужны: учебные данные подключаются как локальные JavaScript-файлы и доступны через `file://`.

## Что реализовано

- реальный маршрут из шести занятий;
- полные модули 01 «Вводное занятие» и 02 «Встреча, консультация и базовые услуги»;
- отмечаемые учебные разделы и внутреннее оглавление длинного модуля 02;
- тесты 6/8 и 8/10 с повторными попытками и темами ошибок;
- пять практических навыков с последовательными уровнями;
- отдельные решения и комментарии наставника;
- автоматическое и осознанное ручное открытие следующего занятия;
- локальный прогресс `progressSchemaVersion: 2` и безопасная миграция v1;
- реальные названия и описания незавершённых модулей 03–06.

Уровень практики не является автоматическим профессиональным допуском. Качество выполнения и дальнейшую готовность подтверждает человек.

## Источники

Иерархия, согласованные исключения и известные расхождения находятся в `content/sources.js`. Согласованные точечные редакционные решения имеют приоритет над общей иерархией.

В модуле 01 используется согласованный блок дезинфекции из основной методички. RESEDA используется только для знакомства с продуктами и не служит технологией премиум-ухода за кожей головы.

## Прогресс и миграция

Данные сохраняются в `localStorage` браузера под ключом `topgun-start-progress`. После закрытия и повторного открытия страницы прогресс остаётся на этом устройстве.

При первом запуске поверх v0.1 приложение переносит только имя, сохраняет исходный JSON в резервной записи миграции и начинает реальный маршрут с модуля 01. Демонстрационные зачёты не переносятся. Сброс требует подтверждения.

## Ограничения

В v0.2 нет полного контента модулей 03–06, технологии детокса, утверждённой формы карты клиента, аккаунтов, синхронизации, сервера и удалённого кабинета наставника. Стабильный архив v0.2 ещё не создавался.
